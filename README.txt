Challenge task
--------------

Predict spatially varying laser track geometry along the scan direction, with calibrated uncertainty, from thermal video, SEM imagery, and profilometer height maps of four directed energy deposition tracks (Track 8, Track 10, Track 14, Track 21).

Approach summary
-----------------

Local track width, left and right boundary position, and a set of cross track contour descriptors (centerline position, peak depth, profile skewness, profile waviness) are predicted as continuous functions of scan position, each with calibrated uncertainty.

All three model families use Gaussian process regression with an isotropic Matern 3/2 kernel. Per sample measurement noise, taken from the profilometer width standard deviation, is passed in as a known alpha term rather than fit as a free white noise kernel. An automatic relevance determination (ARD) kernel and a CNN were also tested. The ARD kernel was unstable given roughly 300 samples per track and 13 free hyperparameters, and the CNN gave very poor negative log likelihood scores, so the isotropic kernel is what we kept.

Model inputs are a 14 feature, physically motivated set that includes cooling rate and linear energy density, both retained after a full ablation study since they improved MAE by roughly 30 percent. A thermal gradient proxy feature was dropped because it hurt MAE in every ablation combination tested, and because Track 21 values for that feature fell almost entirely outside the training range.

Key quantitative results
-------------------------

Direct local width prediction reaches an MAE around 0.120 mm. Width recovered from independently predicted left and right boundaries has a higher MAE, around 0.228 mm, since those boundary models have to learn each track's positional offset from features that do not encode it directly. Full metrics and calibration results are in the report.

How to reproduce our results
-----------------------------

1. Clone the GitHub repository linked in TeamRAV_GitHub_Link.txt.
2. Create a Python environment and install dependencies with pip install -r requirements.txt (Python 3.10 or newer).
3. Download the raw dataset from Zenodo, DOI 10.5281/zenodo.21285367, and place it under data/raw following the layout described in the repository README.
4. Run 02_starter_code_loading_and_visualization_standalone_colab.ipynb to generate the processed Track_8, Track_10, Track_14, and Track_21 folders from the raw data. This step produces both the thermal and height map data used downstream.
5. Run Train_models.ipynb to extract features and train the three GPR model families. This writes trained models, predictions, and figures to ML_results.
6. Run Ablation studies.ipynb to reproduce the feature ablation study and the kernel comparison experiments referenced in the report.

Approximate execution time and hardware requirements
--------------------------------------------------------

The Gaussian process models train on a small number of samples per track (roughly 300), so fitting all three model families is fast, typically well under ten minutes on a standard laptop CPU with no GPU required. The processing notebook that extracts thermal and height data from the raw files takes longer, mainly due to file I/O.
